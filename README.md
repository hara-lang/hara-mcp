# hara-mcp

Language-owned MCP gateway and execution-host coordination for Hara.

The architecture and six-phase delivery plan are tracked in [issue #1](https://github.com/hara-lang/hara-mcp/issues/1). The first implementation slice is tracked in [issue #8](https://github.com/hara-lang/hara-mcp/issues/8).

> This repository is under active construction. It does not yet provide a production MCP endpoint or execute Hara code.
